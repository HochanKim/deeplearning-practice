## 3. 값을 읽을 때

- **`T_S` 는 절대시각이 아니라 경과초다.** 세션이 시작한 순간이 0이며 언제 잰 것인지는 이 파일에 없다. 절대시각은 `T-SP-EXF01_계측세션.csv` 의 `STRT_DT` 가 갖는다. `SESS_ID` 로 두 파일을 이어 `STRT_DT + T_S` 로 계산해야 한다. 진동 계측기의 출력이 원래 경과초이며, 행마다 절대시각을 넣지 않았다
- **`T_S` 는 세션 안에서만 유일하다.** 세션이 다르면 같은 값이 다시 나온다. 정렬·차분·이동평균은 반드시 `SESS_ID` 안에서 할 것
- **세션마다 샘플링 주파수가 다르다.** 계측 길이가 같아도 세션별 행 수가 다르다. 주파수 분석을 세션 간에 비교하려면 주파수축을 맞춰야 한다. `FS_HZ` 는 세션 대장에 있다
- **4채널은 서로 다른 측정 위치다.** 채널 간 상관이 낮아 한 지점의 방향 성분이 아니다. 채널을 평균 내면 위치 정보가 사라진다
- **원파형이다.** 순간값의 분포보다 주파수 구조에 정보가 있다. 세그먼트로 잘라 요약한 표가 `T-SP-EXF01_진동특징.csv` 다
