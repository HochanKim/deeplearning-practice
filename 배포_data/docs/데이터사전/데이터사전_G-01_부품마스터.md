# 데이터사전 — `G-01_부품마스터.csv`

본 데이터는 KAMP 공개 제조AI데이터셋을 원본으로 제철 공정 맥락에 맞게 재구성한 교육용 재현 데이터임. 특정 기업의 실제 조업 데이터가 아님.

---

## 1. 개요

| 항목 | 값 |
|---|---|
| 파일 | `data/G-01_부품마스터.csv` |
| 공정 · 설비 | P제철 전 공장 공용 |
| 계측 | 계측 데이터가 아니라 부품 대장이다 |
| 크기 | 129행 × 6열 |
| 인코딩 | `utf-8-sig` / 줄끝 LF / 구분자 `,` |
| 한 행 | 부품 품목 1종 |

---

## 2. 컬럼

| 컬럼 | 한글명 | 타입 | 단위 | 값 범위 | 결측 | 산출 |
|---|---|---|---|---|---|---|
| `PART_CD` | 부품코드 | 문자열 | — | 129종 (`BFP-001` ~ `WLD-005`) | 0 | 부품교체이력과 잇는 키 |
| `PART_NM` | 부품명 | 문자열 | — | 129종 (`CP 산소 프로브` ~ `훅 블록 베어링`) | 0 |  |
| `PART_TYPE` | 부품군 | 문자열 | — | 19종 (`계장` ~ `회전체`) | 0 |  |
| `APPLY_EQP_TYPE` | 적용 설비유형 | 문자열 | — | 26종 (`고로` ~ `펌프`) | 0 | 설비마스터의 `EQP_TYPE` 과 잇는다. `공통` 은 유형을 가리지 않는다 |
| `STD_LIFE_H` | 표준수명 | 정수 | 시간 | 500 ~ 89,000 | 0 |  |
| `LEAD_TIME_D` | 조달 리드타임 | 정수 | 일 | 5 ~ 90 | 0 |  |

- 컬럼 순서는 `PART_CD` `PART_NM` `PART_TYPE` `APPLY_EQP_TYPE` `STD_LIFE_H` `LEAD_TIME_D`

---

## 3. 값을 읽을 때

- **`APPLY_EQP_TYPE` 에 `공통` 이 섞여 있다.** 설비유형으로 단순 조인하면 공통 부품이 어느 설비에도 붙지 않는다
- **`STD_LIFE_H` 는 설계 표준값이다.** 실제 교체 주기는 정비이력에서 계산해야 하고 둘은 일치하지 않는다
