## 3. 값을 읽을 때

- **이 표의 값은 원본 컬럼이 아니다.** 파형 파일을 2초 세그먼트로 잘라 계산한 값이다. 같은 식을 파형에 적용하면 같은 값이 나오고, 다른 구간 길이나 다른 특징으로 직접 만들어 써도 된다
- **세그먼트 길이는 시간 기준이고 표본 수는 그렇지 않다.** 세션마다 샘플링 주파수가 달라 `N` 이 세션별로 다르다. `N` 을 보지 않고 비교하면 표본 수 차이가 값에 섞인다
- **`_1X` `_2X` `_3X` `_R21` 은 회전주파수를 전제한 차수 성분이다.** 회전수가 달라지면 성립하지 않는다. 이 데이터의 배풍기는 전 세션에서 회전수가 같다
- **`MEAS_DT` 와 `T0_S` 는 기준이 다르다.** 세션 간 비교에는 `MEAS_DT` 를, 세션 안의 위치에는 `T0_S` 를 쓴다
- **세그먼트를 하나의 시계열로 이어 붙이면 안 된다.** 세션 안에서는 연속이지만 세션 사이에는 수십 일의 공백이 있다
- **세션 하나가 세그먼트 수십 개를 낸다.** 세그먼트 단위로 학습·검증을 나누면 같은 세션이 양쪽에 들어간다. 세션 단위로 나눌 것
