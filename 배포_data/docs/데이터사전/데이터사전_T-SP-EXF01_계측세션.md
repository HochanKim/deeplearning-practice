# 데이터사전 — `T-SP-EXF01_계측세션.csv`

본 데이터는 KAMP 공개 제조AI데이터셋을 원본으로 제철 공정 맥락에 맞게 재구성한 교육용 재현 데이터임. 특정 기업의 실제 조업 데이터가 아님.

---

## 1. 개요

| 항목 | 값 |
|---|---|
| 파일 | `data/T-SP-EXF01_계측세션.csv` |
| 공정 · 설비 | 소결 1·2공장 메인 배풍기 (`P1-SP1-EXF01`, `P1-SP2-EXF01`) |
| 계측 | 계측 데이터가 아니라 진동 계측 세션 대장이다 |
| 크기 | 8행 × 6열 |
| 인코딩 | `utf-8-sig` / 줄끝 LF / 구분자 `,` |
| 한 행 | 진동 계측 1회(세션) |

---

## 2. 컬럼

| 컬럼 | 한글명 | 타입 | 단위 | 값 범위 | 결측 | 산출 |
|---|---|---|---|---|---|---|
| `SESS_ID` | 계측세션번호 | 문자열 | — | `V24-SP1-01` / `V24-SP1-02` / `V24-SP1-03` / `V24-SP1-04` / `V24-SP2-01` / `V24-SP2-02` / `V24-SP2-03` / `V24-SP2-04` | 0 | 파형·특징 파일과 잇는 키 |
| `EQP_CD` | 설비코드 | 문자열 | — | `P1-SP1-EXF01` / `P1-SP2-EXF01` | 0 | 설비마스터의 `EQP_TAG` 와 같은 형태다 |
| `STRT_DT` | 계측 시작시각 | 문자열 | — | 2024-01-15 00:00:00 ~ 2024-11-04 00:00:00 | 0 | **파형의 절대시각은 여기서만 나온다** |
| `FS_HZ` | 샘플링 주파수 | 실수 | Hz | 1,314.1 ~ 1,400.6 | 0 | 원본 시간축 간격의 중앙값에서 산출 |
| `DUR_S` | 계측 길이 | 실수 | 초 | 140 ~ 140 | 0 | 파형 마지막 경과초 |
| `ROWS` | 표본수 | 정수 | 개 | 183,969 ~ 196,079 | 0 | 이 세션이 파형 파일에서 차지하는 행 수 |

- 컬럼 순서는 `SESS_ID` `EQP_CD` `STRT_DT` `FS_HZ` `DUR_S` `ROWS`

---

## 3. 값을 읽을 때

- **파형 파일의 절대시각은 이 대장에만 있다.** 파형의 `T_S` 는 경과초이므로 `SESS_ID` 로 이어 `STRT_DT + T_S` 를 계산해야 절대시각이 된다
- **`FS_HZ` 가 세션마다 다르다.** 계측 길이(`DUR_S`)가 거의 같은데도 `ROWS` 가 다른 이유가 이것이다. 세션을 섞어 주파수 분석을 할 때 반드시 확인할 것
- **연속 감시가 아니라 정기 진단이다.** 계측이 연중 몇 차례 흩어져 있고 정기수리 기간을 피해 잡혀 있다. 세션 사이의 공백은 결측이 아니다
- **`ROWS` 는 조인 검산에 쓸 수 있다.** 파형 파일을 `SESS_ID` 로 세었을 때의 행 수와 일치해야 한다
