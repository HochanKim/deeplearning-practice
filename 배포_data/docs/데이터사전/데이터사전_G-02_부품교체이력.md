# 데이터사전 — `G-02_부품교체이력.csv`

본 데이터는 KAMP 공개 제조AI데이터셋을 원본으로 제철 공정 맥락에 맞게 재구성한 교육용 재현 데이터임. 특정 기업의 실제 조업 데이터가 아님.

---

## 1. 개요

| 항목 | 값 |
|---|---|
| 파일 | `data/G-02_부품교체이력.csv` |
| 공정 · 설비 | P제철 전 공장 |
| 계측 | 계측 데이터가 아니라 부품 교체 기록이다 |
| 크기 | 427행 × 4열 |
| 인코딩 | `utf-8-sig` / 줄끝 LF / 구분자 `,` |
| 한 행 | 한 작업지시에서 교체한 부품 1종 |

---

## 2. 컬럼

| 컬럼 | 한글명 | 타입 | 단위 | 값 범위 | 결측 | 산출 |
|---|---|---|---|---|---|---|
| `WO_NO` | 작업지시번호 | 문자열 | — | 380종 (`WO-2024-00005` ~ `WO-2024-02112`) | 0 | 정비이력과 잇는다 |
| `PART_CD` | 부품코드 | 문자열 | — | 71종 (`BFP-001` ~ `WLD-005`) | 0 | 부품마스터와 잇는다 |
| `QTY` | 수량 | 정수 | 개 | 1 ~ 8 | 0 |  |
| `CHG_RSN` | 교체사유 | 문자열 | — | `손상` / `수명도래` / `예방` | 0 | `손상` / `수명도래` / `예방` |

- 컬럼 순서는 `WO_NO` `PART_CD` `QTY` `CHG_RSN`

---

## 3. 값을 읽을 때

- **한 작업지시에 여러 행이 붙는다.** `WO_NO` 는 유일하지 않다. 정비이력과 조인하면 행이 늘어난다
- **같은 내용의 행이 중복으로 들어간 건이 있다.** 실제 대장에서 흔한 중복 입력이다. 지울지 남길지는 분석 목적에 따라 판단해야 한다
