# 데이터사전 — `T-CC-INS01_주편.csv`

본 데이터는 KAMP 공개 제조AI데이터셋을 원본으로 제철 공정 맥락에 맞게 재구성한 교육용 재현 데이터임. 특정 기업의 실제 조업 데이터가 아님.

| 항목 | 값 |

| 공정 · 설비 | 제강 연속주조 주편 검사설비 2대 (`P1-CC1-INS01`, `P1-CC2-INS01`) |
| 계측 | 인발 계통 2점, 오실레이션 계통 2점, 몰드 탕면 1점 |

| 기간 | 2024-01-08 ~ 2024-12-30 |
| 한 행 | 한 시점의 5개 태그 계측값 |

## 3. 값을 읽을 때

- **설비 2대의 값 범위가 겹치지 않는다.** 다섯 태그 전부 `CC1` 과 `CC2` 의 범위가 떨어져 있다. 두 대를 합쳐 학습하면 설비 판별기가 되고, 나누면 한쪽은 슬래브가 몇 개뿐이다. 어느 쪽을 택할지가 이 데이터셋의 첫 판단이다
- **같은 시각에 항상 2행씩 있다.** 두 행을 가르는 컬럼이 없어 중복 기록인지 2채널 동시 계측인지 데이터만으로는 판단할 수 없다. 지우기 전에 무엇인지 정하고 근거를 남길 것
- **시간 간격으로는 슬래브를 나눌 수 없다.** 슬래브 내부에 며칠에 이르는 공백이 있다. 경계는 `SLAB_NO` 가 바뀌는 지점이며 슬래브는 파일 안에서 끊기지 않는다
- **`OSC-STK` 에 이상하게 큰 값이 섞여 있다.** 계측 범위를 벗어난 자릿수이며 센서 오류 코드로 보인다. 그대로 통계에 넣으면 평균·표준편차가 무너진다
- **`MLD-LVL` 은 값이 거칠게 양자화되어 있다.** 고유값이 수십 개뿐이라 연속값처럼 다루면 분포 가정이 어긋난다
- **데이터가 없는 기간이 있다.** 정기수리 2구간을 포함한다. **0으로 채우지 말 것**

## 4. `[가정]` 과 `[확인필요]`

| 표기 | 항목 | 내용 |
|---|---|---|
| `[가정]` | 태그 정의 | 다섯 태그의 의미는 컬럼 사이의 상관 구조를 근거로 P제철 맥락에서 **새로 부여한 정의**다. 인발 속도와 구동 부하가 같이 오르고, 오실레이션 주파수와 스트로크가 서로 반대로 움직이며, 탕면 레벨이 두 계통과 무관하다는 실측에 맞췄다. 원본 의미의 복원이 아니다 |
| `[확인필요]` | 단위 | 원본에 단위 표기가 없다. 값은 계측기 원단위로 보이며 확인 경로가 없다 |
| `[가정]` | 설비 2대 배정 | 원본 2파일의 값 범위가 서로 달라 같은 설비로 보기 어렵다. 제1·제2연주공장의 검사설비로 나눴다 |
