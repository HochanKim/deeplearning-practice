09 역전파와 학습 완성 해설서

08에서 만든 신경망이 틀린 답을 조금씩 고쳐 U자 데이터를 배우는 과정을 설명합니다.
대상 파일은 수업코드/09_역전파와_학습_완성.py입니다.
처음에는 수식을 외우기보다 '무엇을 조금 바꾸면 손실이 어떻게 변할까'라는 질문으로 읽어보세요.
1~14번은 숫자 하나로 손계산, 15~26번은 여러 사례를 한꺼번에 학습하는 코드,
27번부터는 결과 해석과 복습입니다. 각 번호는 이 해설서의 번호입니다.

1) 08에서 09로 이어지는 이야기

08에서는 가중치를 사람이 정하고 그 숫자로 예측하는 순전파를 했다.
09에서는 예측과 실제 정답을 비교하고, 더 잘 맞히도록 가중치를 고친다.
08의 '계산할 수 있다'에서 09의 '데이터로 배울 수 있다'로 넘어가는 것이다.

순전파: 현재 손잡이 값으로 예측 답 만들기.
손실 계산: 답이 얼마나 틀렸는지 숫자로 채점하기.
역전파: 각 손잡이를 바꾸면 손실이 어떻게 변할지 계산하기.
갱신: 그 정보를 이용해 손잡이 값을 실제로 고치기.

역전파와 갱신은 같은 일이 아니다. 방향표를 만드는 일과 실제로 이동하는 일을 구별하자.

2) 이번 파일에는 크기가 다른 두 실험이 있다

앞부분은 입력 하나와 은닉 뉴런 두 개로 계산 원리를 확인한다.
손잡이는 W1, b1, W2, b2, V1, V2, c의 일곱 개다.

뒷부분은 08의 온도 일곱 개를 가지고 은닉 뉴런 여덟 개를 학습한다.
배열로 계산하며 손잡이는 W 여덟 개, b 여덟 개, V 여덟 개, c 한 개로 총 25개다.
앞부분의 수정 결과를 그대로 여덟 뉴런 모델에 이어 붙이는 것은 아니다.
뒤의 fit 함수는 가중치를 새로 초기화하여 학습한다.

3) 먼저 아주 작은 문제 하나를 준비한다

x = 0.30
y = 0.50
W1, b1 = 0.50, 0.10
W2, b2 = -0.40, 0.20
V1, V2, c = 0.30, 0.60, 0.10

x는 입력 재료, y는 실제 정답이다.
코드에서는 온도와 불량의 크기를 줄인 값이라고 설명하지만,
이 부분에서 실제 원자료를 변환하는 계산은 없고 숫자를 직접 지정한다.
y=0.50은 고장 확률 50%라는 뜻이 아니라 이번 숫자 예측 문제의 정답이다.
08과 네트워크 구조는 같고 계산할 숫자는 다르다.

4) 순전파로 중간값을 먼저 구한다

z1 = W1*x+b1 = 0.5*0.3+0.1 = 0.25
z2 = W2*x+b2 = -0.4*0.3+0.2 = 0.08
a1 = sigmoid(z1) ≈ 0.562177
a2 = sigmoid(z2) ≈ 0.519989
y_hat = V1*a1+V2*a2+c ≈ 0.580647

z는 활성화 전 점수이고 a는 활성화를 통과한 중간값이다.
실제 정답 0.5보다 예측이 약 0.080647 높다.
역전파에서는 방금 계산한 a1과 a2 등을 다시 사용한다.
그래서 먼저 앞으로 계산하고 중간값을 기억해야 한다.

5) 이번 벌점은 로그손실이 아니라 제곱오차다

L = (y_hat-y)**2

**2는 제곱이다. 약 0.080647을 제곱하여 손실 L은 약 0.006504가 된다.
03의 로그손실은 고장 확률을 채점했지만, 여기서는 숫자 예측을 제곱오차로 채점한다.
앞부분은 사례 하나이므로 제곱오차 하나다.
뒤에서 일곱 사례를 사용할 때는 제곱오차들의 평균인 MSE를 사용한다.
손실은 작을수록 좋고, 음수와 양수 오차가 서로 지워지지 않게 제곱한다.

6) dL_dW1이라는 긴 이름을 읽는 법

dL_dW1은 'W1을 아주 조금 바꾸면 손실 L이 얼마나 변하는가'라는 기울기다.
수학 표기 dL/dW1을 변수 이름으로 적은 것이다.
여러 손잡이 중 하나만 바꾸는 변화를 보는 것을 편미분이라고 한다.
이름 안의 d나 밑줄이 파이썬에게 자동 미분을 시키는 것은 아니다.
실제 계산은 등호 오른쪽의 곱셈 등으로 직접 작성했다.

기울기가 양수: 그 손잡이를 조금 키우면 손실이 커지는 방향이다.
기울기가 음수: 그 손잡이를 조금 키우면 손실이 작아지는 방향이다.
따라서 손실을 줄이려고 기울기의 반대 방향으로 움직인다.
큰 폭으로 움직여도 반드시 줄어든다는 뜻은 아니다. 지금 위치 근처의 변화 정보다.

7) 왜 뒤에서 앞으로 계산할까

W1은 z1에 영향을 주고, z1은 a1에, a1은 예측에, 예측은 손실에 영향을 준다.

W1 → z1 → a1 → y_hat → L

이 연결을 따라 작은 변화율을 곱하면 W1이 L에 미치는 변화를 구할 수 있다.
이 규칙을 연쇄법칙이라고 한다.
예를 들어 앞 단계 변화가 다음 단계에서 2배, 그다음에서 3배가 되면
처음 변화의 최종 효과는 2*3=6배가 되는 것과 비슷하다.

실제 역전파는 L에서 시작하여 뒤쪽의 공통 계산 결과를 앞쪽 가지들이 재사용한다.
예측에서 출발한 입력값을 거꾸로 복원하는 작업이 아니다.
거꾸로 전달하는 것은 온도가 아니라 '손실에 대한 변화율'이다.

8) 출발점은 예측값에 대한 손실의 기울기다

dL_dyhat = 2*(y_hat-y)

제곱오차 (y_hat-y)**2를 예측값으로 미분하면 이 식이 된다.
이번에는 2*0.080647 ≈ 0.161293이다.
예측이 정답보다 높으므로 예측을 낮추는 방향이 손실을 줄이는 방향임을 보여준다.
이 값은 뒤의 계산으로 전달하는 시작 정보여서 코드에서 '씨앗'이라고 부른다.

처음에는 제곱의 미분 공식을 깊이 유도하기보다
'정답보다 높으면 양수, 낮으면 음수로 출발한다'는 뜻을 먼저 이해하자.

9) 출력층 가중치의 기울기

예측식은 y_hat = V1*a1 + V2*a2 + c다.
V1을 0.001 올리면 다른 값이 같을 때 예측은 a1*0.001만큼 바뀐다.
따라서 V1에서 예측으로 가는 변화율은 a1이다.

dL_dV1 = dL_dyhat*a1 ≈ 0.090675
dL_dV2 = dL_dyhat*a2 ≈ 0.083871
dL_dc  = dL_dyhat*1  ≈ 0.161293

c는 그냥 더하는 값이므로 c가 0.001 늘면 예측도 0.001 늘어난다.
그래서 c가 예측에 미치는 변화율은 1이다.
벌점 자체를 가중치에 배분하는 것이 아니라 각 가중치에 대한 기울기를 구한 것이다.

10) 중간값 a로 한 단계 돌아간다

dL_da1 = dL_dyhat*V1 ≈ 0.048388
dL_da2 = dL_dyhat*V2 ≈ 0.096776

이번에는 V1이 아니라 a1이 조금 변한다고 생각한다.
예측식에서 a1 앞에 붙은 숫자는 V1이므로 변화율 V1을 곱한다.

V1을 바꿀 때는 a1을 곱하고,
a1을 바꿀 때는 V1을 곱한다.
같은 곱셈식이라도 무엇을 움직여 보는지에 따라 남는 숫자가 달라진다.
a1과 a2는 학습으로 직접 고치는 손잡이가 아니라, 앞쪽 손잡이까지 가기 위한 중간 단계다.

11) 시그모이드를 거슬러 올라간다

08에서 배운 sigmoid 도함수는 a*(1-a)였다.

dL_dz1 = dL_da1*a1*(1-a1) ≈ 0.011910
dL_dz2 = dL_da2*a2*(1-a2) ≈ 0.024155

z가 변할 때 a가 얼마나 반응하는지까지 곱하여 z에 대한 손실 기울기를 구한다.
여기서 a1을 다시 sigmoid에 넣는 것이 아니다.
이미 구한 a1로 a1*(1-a1)을 계산한다.
이렇게 순전파의 중간 결과를 재사용하는 것이 역전파의 중요한 특징이다.

12) 입력 가까이에 있는 W와 b까지 도착한다

z1 = W1*x+b1이므로 W1에 대한 z1의 변화율은 x이고 b1에 대한 변화율은 1이다.

dL_dW1 = dL_dz1*x ≈ 0.003573
dL_db1 = dL_dz1   ≈ 0.011910
dL_dW2 = dL_dz2*x ≈ 0.007247
dL_db2 = dL_dz2   ≈ 0.024155

첫 가중치의 전체 연결을 한 줄로 쓰면 다음과 같다.
dL_dW1 = 2*(y_hat-y) * V1 * a1*(1-a1) * x

손실 → 출력 → 은닉 결과 → 활성화 전 점수 → 가중치 순으로 변화율을 곱한 식이다.
이번 숫자에서는 일곱 기울기가 모두 양수지만 모든 문제에서 그런 것은 아니다.
여러 경로가 같은 변수로 모이는 구조에서는 경로별 기여를 더하는 단계도 필요하다.

13) 수치미분으로 역전파 답안을 검사한다

params = {'W1': W1, 'b1': b1, ...}

이름과 값을 짝지어 담는 것을 딕셔너리라고 한다.
params['W1']은 W1 이름표에 해당하는 숫자를 꺼낸다.
실제 코드에는 점 세 개 대신 일곱 이름과 값이 모두 들어 있다.

plus = dict(params)
minus = dict(params)
plus[이름] += h
minus[이름] -= h

dict(params)는 이 숫자 목록의 복사본을 만든다.
한쪽에서 검사할 손잡이만 h 올리고 다른 쪽에서는 h 내린다.
h=1e-5는 0.00001이다.

(손실계산(**plus)-손실계산(**minus))/(2*h)

양옆 손실 차이를 두 위치 사이 거리로 나눠 기울기를 근사한다.
여기서 **plus는 딕셔너리를 W1=..., b1=... 같은 이름 붙은 인자로 펼쳐 준다.
숫자 **2의 제곱과는 위치와 용도가 다른 문법이다.

역전파grad에는 역전파로 구한 기울기를 같은 이름표로 담아 두었다.
abs(bp-num)<1e-6이면 두 값의 차이가 0.000001보다 작은지 확인한다.
일곱 개가 모두 True였다. 현재 계산점에서 두 방식이 잘 맞는다는 검증이다.
모두일치 = 모두일치 and 일치는 한 번이라도 False가 나오면 최종 결과도 False가 되게 한다.

14) 이제 실제 손잡이를 한 번 고친다

새값 = {이름: params[이름]-lr*역전파grad[이름] for 이름 in params}

모든 이름을 차례로 꺼내 '기존 값 - 학습률*기울기'로 새 딕셔너리를 만든다.
리스트 컴프리헨션과 비슷하지만 중괄호와 이름:값을 써서 딕셔너리를 만든다.
이번 lr은 0.5다.

V1 새 값 ≈ 0.30 - 0.5*0.090675 = 0.254662
c 새 값  ≈ 0.10 - 0.5*0.161293 = 0.019353

나머지 손잡이도 같은 방식으로 바꾼다.
기울기는 모두 변경 전 같은 상태에서 구한 것을 사용한다.
앞부분 코드는 원본 params를 덮어쓰지 않고 새값으로 다시 손실을 계산한다.

갱신 전 손실 약 0.006504 → 갱신 후 약 0.002454.
약 62% 줄었다. 그렇다고 예측 정확도가 62%가 됐다는 뜻은 아니다.
한 번의 충분한 이동이 항상 보장되는 것은 아니고 학습률이 너무 크면 오히려 손실이 늘 수 있다.

15) 이제 온도 일곱 개를 함께 배운다

온도 = np.array([10, 15, 20, 25, 30, 35, 40], dtype=float)
불량 = np.array([9, 5, 2, 1, 2, 5, 9], dtype=float)

08의 U자 데이터를 NumPy 배열로 만든다.
dtype=float는 소수를 계산할 수 있는 실수형으로 담으라는 뜻이다.
은닉 뉴런 수는 기본 여덟 개로 늘린다.
앞에서 한 뉴런씩 계산하던 원리를 여러 뉴런과 여러 사례에 동시에 적용한다.

뒤에서 sigmoid라는 함수를 다시 정의한다.
같은 이름의 새 정의가 그 이후 사용되며 math.exp 대신 np.exp로 배열을 함께 계산한다.
모델이 배우다가 활성화를 저절로 바꾸는 것이 아니라 코드가 함수 정의를 바꾼 것이다.

16) 배열 모양을 먼저 이해하자

현재 사례 수 n=7, 은닉 뉴런 수 H=8이다.
X: (7, 1) 입력 온도 하나씩을 담은 일곱 행.
Y: (7, 1) 정답 불량 하나씩을 담은 일곱 행.
W: (1, 8) 입력에서 여덟 뉴런으로 가는 가중치.
b: (1, 8) 여덟 뉴런의 편향.
Z와 A: (7, 8) 각 사례를 여덟 뉴런이 계산한 결과.
V: (8, 1) 여덟 은닉 결과를 출력 하나로 조합하는 가중치.
c: (1, 1) 출력 편향 하나.
y_hat: (7, 1) 각 사례의 예측 하나씩.

표의 행은 사례, 은닉 계산 표의 열은 뉴런이다.
센서가 여덟 개로 늘어난 것이 아니다. 센서는 온도 하나이고 중간 계산 담당자가 여덟 명이다.

17) NumPy 순전파는 앞 계산을 묶은 것이다

Z = X @ W + b
A = sigmoid(Z)
y_hat = A @ V + c
return y_hat, A

@는 행렬곱이다. 연결되는 값들을 곱해서 합친다.
X @ W는 일곱 입력 각각에 여덟 가중치를 적용하여 (7, 8)을 만든다.
b의 여덟 값은 각 행에 맞춰 반복 적용된다. 이를 브로드캐스팅이라고 한다.
A @ V는 사례마다 여덟 중간 결과를 조합해 최종 답 하나를 만든다.
A는 역전파에서 다시 쓰려고 예측값과 함께 돌려준다.

18) 평균 손실에서는 왜 n으로 나눌까

손실 = np.mean((y_hat-Y)**2)
dy_hat = 2*(y_hat-Y)/n

앞부분은 사례 하나의 손실이었다.
이번에는 일곱 제곱오차의 합을 일곱으로 나눈 평균이므로 기울기에도 /n이 들어간다.
각 사례가 평균 손실에 기여하는 몫을 계산하는 것이다.
dy_hat은 이름이 짧아졌지만 의미는 각 예측값에 대한 손실의 기울기다.
예측값 자체를 수정하라는 명령이 아니다.

19) 출력층 배열 기울기

dV = A.T @ dy_hat
dc = dy_hat.sum(axis=0, keepdims=True)

.T는 행과 열을 바꾸는 전치다. A의 (7, 8)을 (8, 7)로 바꾼다.
그러면 각 뉴런이 일곱 사례에서 보인 중간값과 기울기를 곱해 더할 수 있다.
결과 dV는 V와 같은 (8, 1) 모양이다.
이는 앞부분의 dL_dV1=dL_dyhat*a1을 사례 전체에 대해 모은 것이다.

c는 모든 사례에 공통으로 더해졌으므로 사례별 기울기를 더한다.
axis=0은 행 방향으로 모아 열별 합을 구하라는 뜻이다.
keepdims=True는 더한 뒤에도 차원을 유지해 dc를 (1, 1)로 만든다.
dy_hat에서 이미 n으로 나눴으므로 여기서 평균을 또 내지 않는다.

20) 은닉층 배열 기울기

dA = dy_hat @ V.T
dZ = dA * A * (1-A)
dW = X.T @ dZ
db = dZ.sum(axis=0, keepdims=True)

dA: 출력층 가중치를 따라 각 뉴런으로 변화율을 전달한다. (7, 8)
dZ: 각 자리에서 시그모이드 도함수 A*(1-A)를 곱한다. (7, 8)
dW: 입력과 변화율을 곱하고 사례 전체의 기여를 모은다. (1, 8)
db: 각 뉴런의 편향에 대한 기여를 사례 전체에서 더한다. (1, 8)

@는 곱해서 더하는 행렬곱이고 *는 여기서 같은 자리끼리 곱하는 계산이다.
활성화 미분 dZ에서 @를 쓰면 같은 의미가 아니다.
dW, db, dV, dc는 각각 수정할 W, b, V, c와 모양이 같다.
모양이 맞는지 확인하면 배열 코드를 이해하고 오류를 찾기 쉽다.

21) fit 함수가 전체 학습을 담당한다

def fit(x, y, 은닉수=8, lr=0.1, epochs=3000, 로그=False, 표준화쓰기=True):

함수를 부를 때 생략한 설정은 등호 뒤 기본값을 쓴다.
은닉수는 중간 뉴런 개수, lr은 학습률, epochs는 반복 횟수다.
로그는 중간 결과를 출력할지 정하는 스위치다.
표준화쓰기는 입력 눈금을 바꿀지 정하는 스위치다.
이 fit은 사이킷런에서 가져온 함수가 아니라 이 파일에서 직접 만든 함수다.

한 바퀴에서 일곱 사례 전체의 순전파와 역전파를 계산하고 한 번 갱신한다.
따라서 여기서는 한 epoch에 한 번 갱신하는 전체 배치 학습이다.
사례 하나씩 따로 일곱 번 고치는 방식은 아니다.

22) 표준화한 눈금도 모델과 함께 기억한다

m, s = x.mean(), x.std()
z = (x-m)/s
X = z.reshape(-1, 1)
Y = y.reshape(-1, 1)

m은 입력 평균, s는 입력 표준편차다.
이번 온도 평균은 25이고 표준편차는 10이다.
입력은 [-1.5, -1, -0.5, 0, 0.5, 1, 1.5]로 바뀐다.
reshape(-1, 1)은 열을 하나로 맞추고 행 수는 자동 계산하여 세로 표로 만든다.
뒤쪽 학습에서는 입력만 표준화하고 정답 [9, 5, 2, 1, 2, 5, 9]는 그대로 사용한다.
정답을 0~1로 바꾸었던 앞부분의 설명용 숫자와 혼동하지 말자.

표준화를 끄면 z=x, m=0, s=1로 둔다.
나중의 (x-m)/s가 x 그대로 되게 하는 설정이다.
이 함수에는 표준편차 0 처리 코드가 없으므로 입력이 모두 같은 다른 데이터에는 보완이 필요하다.

23) 가중치는 왜 무작위로 시작할까

np.random.seed(0)
W = np.random.randn(1, 은닉수)*0.5
b = np.zeros((1, 은닉수))
V = np.random.randn(은닉수, 1)*0.5
c = np.zeros((1, 1))

randn은 평균 0, 표준편차 1인 정규분포를 따르는 난수를 만든다.
0.5를 곱해 초기 숫자의 크기를 줄인다. 모든 값이 -0.5~0.5에 갇힌다는 뜻은 아니다.
zeros는 해당 모양을 0으로 채운다.
seed(0)은 같은 조건으로 다시 시작할 때 결과를 재현하기 위한 난수 설정이다.

모든 은닉 뉴런의 연결을 똑같이 초기화하면 같은 역할로 움직이며 서로 다른 특징을 배우기 어렵다.
W와 V를 다르게 시작해 그 대칭을 깨는 것이다.
b와 c가 0인 것은 괜찮다. 모든 가중치까지 동일하게 시작하는 경우와 다르다.

24) 학습 반복문은 세 동작이다

y_hat, A = 순전파(X, W, b, V, c)
dW, db, dV, dc = 역전파(X, Y, A, y_hat, V)
W -= lr*dW
b -= lr*db
V -= lr*dV
c -= lr*dc

앞으로 계산 → 뒤로 기울기 계산 → 손잡이 수정의 반복이다.
-=는 기존 값에서 오른쪽 값을 빼서 갱신하는 문법이다.
모든 기울기를 먼저 구해 두었으므로 네 갱신 줄이 차례로 실행되어도 같은 이전 상태의 기울기를 쓴다.

if 로그 and epoch % 500 == 0:

로그가 True이고 반복 번호가 500으로 나누어떨어질 때만 출력한다.
%는 나머지, and는 두 조건을 모두 만족하는지 확인한다.
epoch는 0부터 세며, epoch 0 출력도 첫 갱신을 마친 뒤의 손실이다.
마지막 epoch 3000 표시는 반복이 모두 끝난 후 따로 출력한 결과다.

25) 학습한 모델은 여섯 묶음으로 돌려준다

return (W, b, V, c, m, s)

여섯 숫자만 있다는 뜻은 아니다. 앞의 네 항목은 여러 숫자를 담은 배열이다.
W, b, V, c는 배운 손잡이이고 m, s는 예측할 때 재사용할 눈금이다.
이 파일에서는 이 묶음을 '모델' 변수에 담아 보관한다.
학습 결과를 파일로 저장하는 코드는 이 파일에는 없다.

26) predict는 새 입력으로 답만 만든다

W, b, V, c, m, s = 모델
z = (np.asarray(x, dtype=float)-m)/s
y_hat, _ = 순전파(z.reshape(-1, 1), W, b, V, c)
return y_hat.ravel()

asarray는 입력을 NumPy 배열로 다룰 수 있게 변환한다.
학습 때 저장한 m과 s로 눈금을 바꾸고 순전파만 실행한다.
_는 여기서 반환된 A를 이후 사용하지 않겠다는 관례적인 이름이다.
ravel은 (7, 1) 같은 세로 표를 (7,)인 한 줄 배열로 편다.
predict 안에는 역전파나 가중치 갱신이 없다. 예측할 때마다 다시 배우는 것이 아니다.

출력 번호 2000에서 약 0.0019

예측과 정답의 제곱 차이가 점점 작아졌다는 뜻이다.

28) 표준화를 끈 비교 실험

표준화 미사용 최종 손실: 약 9.3429

그곳에서는 a*(1-a)가 작아져 앞쪽으로 전달되는 기울기가 약해질 수 있다.

30) assert는 예상한 조건이 맞는지 확인하는 장치다

assert mlp손실 < 직선손실, 'MLP 가 직선보다 못하면 학습이 잘못된 것!'
assert mlp손실 < 0.01, '손실이 충분히 줄지 않았다 = 학습 실패!'

조건이 참이면 계속 진행한다. 거짓이면 오류와 메시지를 낸다.
이번 실행에서는 두 조건이 모두 통과했다.
이는 이 수업 데이터와 설정에서 기대하는 결과를 확인하는 검사다.
신경망이 어떤 데이터에서도 직선보다 반드시 좋아야 한다는 법칙은 아니다.

31) 학습 점수와 새로운 문제의 실력은 다르다

이 파일은 일곱 사례 전부로 배우고 같은 일곱 사례로 채점한다.
학습용·시험용 분할은 하지 않는다.
목적은 역전파 구현과 비선형 패턴 학습을 확인하는 것이다.

따라서 온도 22나 100에서도 잘 맞는지까지 입증한 것은 아니다.
predict([22], 모델)로 숫자는 구할 수 있지만, 별도 실제 정답이 없으면 맞는지는 알 수 없다.
새 데이터에 대한 성능을 확인하려면 앞의 02~04처럼 적절히 분리해서 평가해야 한다.

32) 사이킷런 모델과 비교하는 이유

MLPRegressor(
    hidden_layer_sizes=(8,),
    activation='logistic',
    solver='lbfgs',
    max_iter=5000,
    random_state=0
)

hidden_layer_sizes=(8,)은 은닉층 하나에 뉴런 여덟 개라는 뜻이다.
괄호 속 쉼표는 항목 하나짜리 튜플을 만드는 문법이다.
activation='logistic'은 은닉층에 시그모이드를 쓰겠다는 설정이다.
출력은 회귀용 숫자이며 고장 분류로 바뀌는 것이 아니다.
solver='lbfgs'는 가중치를 찾는 최적화 방법이다. 직접 만든 경사하강 반복문과 다르다.
max_iter는 최대 반복 횟수라 반드시 5000번을 끝까지 수행한다는 뜻은 아니다.

현재 출력에서는 사이킷런도 일곱 점의 U자 패턴을 잘 맞혔다.
다만 초기화·최적화·기본 규제 등 세부 설정이 달라 동일한 가중치를 얻는 비교는 아니다.
역전파 공식 자체의 직접적인 검증은 앞의 수치미분 대조가 담당한다.
try와 except ImportError는 사이킷런이 없으면 이 비교 부분만 건너뛰게 한다.

33) 뉴런을 늘리면 항상 더 잘 배울까

뉴런 2개 → 최종 학습 손실 약 0.0139
뉴런 4개 → 약 0.0072
뉴런 8개 → 약 0.0006
뉴런 16개 → 약 0.0009

은닉수만 바꾸어 fit을 다시 실행한 결과다.
뉴런이 많으면 표현할 수 있는 관계가 풍부해질 수 있지만,
같은 학습률과 같은 반복 횟수에서 항상 더 낮은 손실에 도달하는 것은 아니다.
모양이 달라지면 초기 난수 배열과 학습 과정도 달라진다.

여기서 16개의 학습 손실이 조금 더 높다는 사실만으로 과적합이라고 판단할 수는 없다.
과적합은 학습 성능과 별도의 검증·시험 성능을 함께 봐야 한다.
이 실험에서는 평가용 새 데이터가 없다는 점을 기억하자.

34) 초심자가 가장 헷갈리기 쉬운 구별

손실 L: 얼마나 틀렸는지 나타내는 벌점 숫자.
기울기 dW: W를 조금 바꾸면 그 벌점이 어떻게 바뀔지 나타내는 정보.
학습률 lr: 기울기를 이용해 한 번에 얼마나 고칠지 정하는 크기.
가중치 W: 실제 예측 계산에 사용하는, 학습으로 바뀌는 숫자.

순전파는 값을 계산한다.
역전파는 기울기를 계산한다.
경사하강 갱신은 가중치를 수정한다.
이 과정을 반복하는 전체가 이번 학습이다.

35) 스스로 풀어보는 복습 문제

질문: dL_dV1에서 왜 a1을 곱할까?
답: 예측식 V1*a1에서 V1을 조금 바꾸면 예측이 그 변화의 a1배만큼 바뀌기 때문이다.

질문: dL_da1에서는 왜 V1을 곱할까?
답: 이번에는 a1을 움직이므로 a1 앞의 계수 V1이 변화율이 되기 때문이다.

질문: 기울기가 -2이고 lr=0.1이면 손잡이는 어떻게 바뀔까?
답: 기존 값 - 0.1*(-2)이므로 기존 값보다 0.2 증가한다.

질문: 일곱 사례의 역전파 씨앗에 왜 /7이 붙을까?
답: 손실이 일곱 제곱오차의 합이 아니라 평균이기 때문이다.

질문: predict에서 역전파를 할까?
답: 아니다. 저장한 눈금과 손잡이로 순전파만 한다.

질문: 08의 뉴런 두 개와 09 뒤쪽의 뉴런 여덟 개는 센서 개수일까?
답: 아니다. 입력 센서는 온도 하나이고 은닉층에서 계산하는 뉴런 수다.

질문: 학습 손실이 아주 작으니 현장 성능도 검증됐을까?
답: 아니다. 이 파일은 같은 일곱 점으로 배우고 평가했으므로 새 데이터 검증이 따로 필요하다.

36) 코드 전체의 흐름 다시 읽기

작은 사례 하나로 순전파

→ 경사하강으로 한 번 갱신하여 손실 감소 확인

→ 표준화와 무작위 초기화
→ 순전파·역전파·갱신을 3000번 반복
→ 표준화 유무 비교와 U자 학습 결과 확인
