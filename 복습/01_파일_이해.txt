1) "직선을 하나 만들고 -> 얼마나 틀렸는지 재고 -> 어느 방향으로 고치면 덜 틀리는 지 확인하고
-> 조금씩 고치는 일을 반복해서 가장 좋은 직선을 찾는다"

2) pandas로 예측용으로 사용할 데이터 x와 실제 데이터 y를 꺼내고
numpy로 예측 -> 손실 -> 기울기 -> w(가중치), b(절편) 수정 -> 반복 -> 가장 좋은 직선 -> 새 값 예측 -> R^2 

3) astype(float)은 '데이터의 숫자들을 전부 실수 형태로 바꾸기' 기능이 담긴 메서드인데
머신러닝 계산 목적으로 가져온 숫자들의 편리한 계산을 위해 선언하는 것이다

4) 데이터 예측값을 구하는 공식은 'w * x + b'이다, 
이는 수학에서 그래프 기울기 공식(a*x + b)과 동일하다

5) 모델이 "x에 어떤 숫자(w)를 곱하고, 어떤 숫자(b)를 더해서 y의 실측 데이터를 잘 맞힐 수 있을까?'
를 찾는 것이다

6) numpy는 for문과 같은 반복문을 사용해서 값을 직접 돌려가며 계산하지 않고
많은 데이터들을 자동으로 각각 계산을 해서 값을 돌려준다 (벡터화 연산)

7) 예측을 통해 계산한 값을 실제 값인 y와 비교하면서 손실 정도를 알 수 있다

8) 오차들을 더하면 0이 나와 컴퓨터가 완벽한 예측으로 오판할 수 있으므로
오차들을 제곱하여 평균을 계산한다 (MSE, 평균제곱오차의 개념)

9) MSE가 작을수록 오차가 적다는 의미로 좋게 평가할 수 있다

10) 가중치(w)와 절편(b)에서 절편을 조금씩 조정하면 
어느 쪽으로 떨어지고 오르는지를 알 수 있는데 이것이 경사하강법 개념

11) 미분 = 지금 여기서 조금 움직였을 때 값이 어느 방향으로 얼마나 변하는지 알아보는 것

12) 편미분 = 손잡이가 여러 개일 때 하나만 움직여보는 미분

13) w와 b 각각 어느 쪽으로 움직여야 하는지 알려주는 방향표와 같은 개념이 Gradient(그래디언트)

14) lr(learning rate)는 학습률을 의미하며 이 값에 따라 '한 번에 얼마나 크게 걸을까?'를 알 수 있다
=> 학습률은 '틀린 답을 고칠 때 한 번에 얼마나 크게 고칠지 정하는 값이다.'

15) 경사하강법은 "현재 위치에서 기울기를 확인하고, 손실이 작아지는 반대 방향으로 조금 이동하는 것을 반복하는 것."

16) x의 값이 크면 예측을 구할때 가중치를 조금씩 변화를 줘도
예측식의 크기가 커지는 데 많은 가중치를 주면 발산이 나올 수 있다

17) 이런 이유로 값을 '표준화'하는 것이 등장한다, 정보를 없앤 게 아닌 눈금만 바꾼 것

18) 경사하강법 → MSE가 가장 작은 w,b를 걸어서 찾음
최소제곱 공식 → MSE가 가장 작은 w,b를 계산해서 찾음

19) R² ≈ 1
→ 아주 잘 설명

R² ≈ 0
→ 평균만 찍는 것과 비슷

R² < 0
→ 평균만 찍는 것보다도 못함
