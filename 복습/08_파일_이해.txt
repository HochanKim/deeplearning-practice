08 선형의 벽과 순전파 해설서

온도 하나가 신경망 안에서 어떤 계산을 거쳐 예측값이 되는지 배우는 자료입니다.
대상 코드는 수업코드/08_선형의_벽과_순전파.py입니다.
이름에 공백이 들어간 다른 파일이 아니라 현재 밑줄로 연결된 파일을 기준으로 설명합니다.
먼저 1~7번에서 문제를 이해하고, 8~17번에서 순전파를 따라 계산해 보세요.
18~25번은 활성화와 도함수, 26번부터는 실습과 NumPy 연결입니다.

1) 이번 수업에서 가장 먼저 구별할 두 가지

순전파: 현재 가중치로 예측값을 계산하는 일.
학습: 예측을 정답과 비교하고, 더 잘 맞히도록 가중치를 고치는 일.

08의 신경망은 순전파만 한다. 가중치는 사람이 정해 놓았다.
신경망의 가중치를 데이터로 고치는 학습은 다음 09에서 다룬다.
단, 08 앞부분의 비교용 직선은 데이터에서 가장 잘 맞는 계수를 계산한다.
따라서 '파일 전체에서 아무것도 학습하지 않는다'기보다
'신경망은 아직 학습하지 않는다'라고 구별하면 정확하다.

2) 앞에서 배운 내용과 연결하기

01과 02: 입력에 가중치를 곱하고 절편을 더해서 숫자를 예측했다.
03: 그 점수를 시그모이드에 넣어 고장 확률로 사용했다.

이미 알던 부품을 새로운 순서로 연결하는 것이다.

3) 이번 데이터는 CSV에서 읽지 않는다

온도 = [10, 15, 20, 25, 30, 35, 40]
불량 = [9, 5, 2, 1, 2, 5, 9]

코드 안에 직접 쓴 작은 설명용 데이터다. 실제 측정 자료로 단정하지 말자.
두 목록은 같은 번호끼리 짝이다.
온도 10의 실제 불량 값은 9이고, 온도 25의 실제 불량 값은 1이다.

여기의 불량은 03처럼 정상 0과 고장 1로 구별하는 이름표가 아니다.
1, 2, 5, 9 같은 숫자 크기를 예측하는 회귀 문제다.
코드가 불량 수치의 단위를 별도로 정하지 않았으므로 불량률 9%라고 읽지는 않는다.

4) 왜 U자 데이터라고 부를까

온도가 10에서 25로 올라갈 때 불량 값은 9 → 5 → 2 → 1로 내려간다.
온도가 25에서 40으로 더 올라가면 1 → 2 → 5 → 9로 다시 올라간다.
가운데가 낮고 양 끝이 높아서 점들을 그리면 U자 모양이다.

직선 하나는 계속 올라가거나, 계속 내려가거나, 수평일 수 있다.
내려가다가 다시 올라가는 골짜기를 직선 하나로 표현할 수는 없다.
이 예제에서 '선형의 벽'은 원래 온도 x에 대해 w*x+b만 쓰는 모델의 표현 한계다.
신경망만 유일한 해결책은 아니다. 제곱 특징을 넣거나 다른 비선형 모델을 쓸 수도 있다.

5) 평균 함수와 예측 함수를 읽어보자

def 평균(값들):
    return sum(값들) / len(값들)

def는 함수를 만드는 문법이다. 함수는 이름을 붙여 놓은 계산 방법이다.
sum은 모두 더하기, len은 개수 세기, return은 결과 돌려주기다.
불량 값의 합은 33이고 개수는 7이므로 평균은 33/7, 약 4.7143이다.

def 예측하기(xs, w, b):
    return [w * x + b for x in xs]

xs의 숫자를 하나씩 x에 넣고 w*x+b를 계산하여 새 목록으로 만든다.
이 문법을 리스트 컴프리헨션이라고 한다.
xs는 여러 입력을 담은 이름이고 x는 그중 하나를 가리키는 이름이다.

6) 가장 잘 맞는 직선인데도 가로로 누워 버린다

x_bar, y_bar = 평균(온도), 평균(불량)

x_bar는 온도 평균 25, y_bar는 불량 평균 약 4.7143이다.
그다음 긴 w 수식은 제곱오차 합이 가장 작은 직선의 기울기를 구하는 공식이다.
zip(온도, 불량)은 (10, 9), (15, 5)처럼 입력과 정답을 짝짓는다.
** 2는 제곱이고, sum(계산식 for ...)은 계산한 값들을 더한다.

여기서는 평균 온도 양쪽에 같은 불량 값이 대칭으로 있다.
w 수식의 분자에서 왼쪽과 오른쪽의 기여가 서로 상쇄되어 0이 된다.
b = y_bar - w*x_bar이므로 b는 평균 불량과 같아진다.

실행 결과: w = 0, b ≈ 4.7143.
어떤 온도를 넣어도 4.7143이라고 답하는 수평선이다.
코드가 고장 난 것이 아니다. 허용된 직선들 중 제곱오차 기준으로 이것이 최선이다.

7) R²가 0이라는 말의 정확한 뜻

SSE = 모델 예측의 제곱오차를 모두 더한 값.
SST = 매번 정답 평균만 답했을 때의 제곱오차를 모두 더한 값.
R² = 1 - SSE / SST.

이번 모델은 매번 평균을 답하므로 SSE와 SST가 같다.
그래서 R² = 1 - 1 = 0이다.
정답을 한 개도 못 맞혔다는 뜻이 아니라 평균만 답하는 기준과 같다는 뜻이다.
R²는 음수가 될 수도 있어서 0이 최저점은 아니다.

다른 데이터에서 R²가 0이라는 사실 하나만으로 '선형모델로 불가능'을 증명할 수는 없다.
이번에는 U자 모양과 최적 직선 계산을 함께 보아 표현 한계를 확인한 것이다.
출력의 오차 y-p가 양수면 예측이 실제보다 작고 음수면 예측이 실제보다 크다.

8) 뉴런은 작은 계산 담당자다

뉴런 하나는 입력을 받아 다음 두 일을 한다.
첫째, 가중치를 곱하고 편향을 더해 점수 z를 만든다.
둘째, 활성화 함수 g를 통과시켜 결과 a를 만든다.

z = W*x + b
a = g(z)

편향 b는 앞에서 배운 절편과 같은 역할의 더하는 값이다.
뉴런은 실제 작은 사람이 아니라 이런 계산을 하는 단위를 부르는 이름이다.

9) 은닉층과 출력층을 구별하자

입력: 온도 x 하나.
은닉층: 뉴런 1과 뉴런 2가 같은 온도를 받아 각각 계산하는 중간 단계.
출력층: 두 뉴런의 결과를 조합하여 최종 예측 하나를 만드는 단계.

입력 x → 뉴런 1의 결과 a1 ─┐
       → 뉴런 2의 결과 a2 ─┴→ 최종 예측 y_hat

은닉층이라는 말은 입력과 최종 출력 사이의 중간층이라는 뜻이다.
뉴런 1의 결과가 뉴런 2에 들어가는 직렬 구조가 아니다.
두 뉴런 모두 같은 x를 받고, 두 결과가 출력층에서 합쳐진다.
MLP는 이런 계산 단위들을 층으로 연결한 신경망 종류다.
이번 구조는 은닉층 하나와 출력층 하나를 가진 작은 모델이다.

10) 기호를 일곱 개의 조절 손잡이로 읽기

W1: 온도를 뉴런 1에서 얼마나 곱할지.
b1: 뉴런 1의 점수에 얼마나 더할지.
W2: 온도를 뉴런 2에서 얼마나 곱할지.
b2: 뉴런 2의 점수에 얼마나 더할지.
V1: 뉴런 1의 결과 a1을 얼마나 곱해서 사용할지.
V2: 뉴런 2의 결과 a2를 얼마나 곱해서 사용할지.
c: 마지막에 공통으로 얼마나 더할지.

W와 V는 연결 위치를 구별하기 위해 다르게 붙인 가중치 이름이다.
b1, b2, c는 편향이다. 합쳐서 학습으로 조절할 숫자가 일곱 개다.
z1, z2, a1, a2는 계산 중 생긴 값이며 별도 학습 손잡이가 아니다.
y_hat 또는 ŷ는 예측값, y는 실제 정답을 뜻한다.

11) 시그모이드는 점수를 부드럽게 눌러준다

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

math는 파이썬에 포함된 수학 도구다.
math.exp(-z)는 약 2.718인 수 e의 -z제곱을 계산한다.
처음에는 수식보다 다음 관계를 먼저 기억하자.

z=-3 → 약 0.0474
z=-1 → 약 0.2689
z= 0 → 0.5000
z= 1 → 약 0.7311
z= 3 → 약 0.9526

낮은 점수는 0 쪽, 높은 점수는 1 쪽으로 가고 가운데에서 부드럽게 변한다.
그림으로 그리면 S자 모양이다.
03에서는 최종 고장 확률을 만드는 데 썼다.
여기서는 은닉층의 중간 계산에 쓰므로 a1과 a2를 각각 불량 확률로 읽지 않는다.

12) ReLU는 음수만 잘라낸다

def relu(z):
    return max(0.0, z)

max는 두 값 중 큰 것을 고른다.
z=-3이면 0, z=0이면 0, z=3이면 3이다.
음수 구간은 평평하고 양수 구간은 그대로 올라가므로 0에서 꺾인다.
시그모이드처럼 출력을 1 이하로 제한하지 않는다.

비선형이라는 말은 부드러운 곡선만 뜻하지 않는다.
ReLU처럼 전체를 직선 하나로 표현할 수 없는 꺾은선도 비선형이다.
ReLU는 많이 쓰이는 활성화지만 모든 신경망의 은닉층이 반드시 ReLU인 것은 아니다.

13) 현재 파일에서 실제로 사용하는 숫자

W1, b1 = 0.3, -6.0
W2, b2 = -0.2, 5.0
V1, V2, c = 4.0, -3.0, 1.0

현재 활성화된 설정은 이 값들이다.
파일의 다른 V1, V2, c 설정 앞에는 #이 붙어 있어 실행되지 않는다.
#으로 시작하는 줄은 설명인 주석이다. 그 안의 출력 예시는 과거 실험 기록이다.
주석 속 숫자를 바꾸는 것만으로 실행 결과가 달라지지는 않는다.

14) 온도 25를 넣어 손으로 순전파 계산하기

첫 단계는 은닉층 점수 두 개를 만드는 것이다.
z1 = 0.3*25 - 6 = 1.5
z2 = -0.2*25 + 5 = 0

둘째 단계는 두 점수에 활성화를 적용하는 것이다.
a1 = sigmoid(1.5) ≈ 0.817574
a2 = sigmoid(0) = 0.5

셋째 단계는 출력층에서 조합하는 것이다.
y_hat = 4*a1 - 3*a2 + 1
      ≈ 3.270298 - 1.5 + 1
      ≈ 2.770298

소수점 아래 네 자리로 표시하면 2.7703이다.
중간값 0.8176을 먼저 반올림해 손으로 계산하면 마지막 자리가 조금 달라질 수 있다.
코드는 내부에서 더 많은 자릿수를 유지하고 표시할 때만 반올림한다.
실제 정답은 1이지만 가중치를 아직 학습하지 않아 예측이 어긋난 것이다.

15) 순전파 함수를 한 줄씩 읽기

def 순전파(x, 활성화):
    z1 = W1 * x + b1
    z2 = W2 * x + b2
    a1 = 활성화(z1)
    a2 = 활성화(z2)
    y_hat = V1 * a1 + V2 * a2 + c
    return y_hat, z1, z2, a1, a2

괄호 속 x와 활성화는 함수를 부를 때 전달받을 재료다.
파이썬에서는 숫자뿐 아니라 함수도 재료처럼 전달할 수 있다.
순전파(25, sigmoid)는 온도 25와 시그모이드 계산 방법을 전달한다.
순전파(25, relu)는 온도는 그대로 두고 활성화 방법만 바꾼다.

sigmoid라고 괄호 없이 쓰는 것은 함수를 전달하는 것이다.
sigmoid(25)는 그 자리에서 함수를 실행하여 나온 숫자를 뜻하므로 다르다.
함수 안의 활성화(z1)에서 전달받은 함수를 실제로 실행한다.

16) 반환값과 대괄호를 이해하기

y_hat, z1, z2, a1, a2 = 순전파(25, sigmoid)

함수가 돌려준 다섯 값을 순서대로 다섯 이름에 담는다.
중간 계산을 눈으로 확인하기 위해 예측값 외에도 네 값을 돌려주는 것이다.

순전파(25, sigmoid)[0]

[0]은 반환값 중 첫 번째인 y_hat만 꺼낸다.
파이썬은 위치를 0부터 세므로 [1]은 z1이고 [4]는 a2다.
print의 f 문자열은 중괄호 안의 값을 글에 넣는다.
:.4f는 소수 네 자리, :+8.4f는 부호를 붙이고 최소 8칸 폭에 소수 네 자리로 표시한다.
이 표시는 계산법이 아니라 화면에서 보이는 형식을 바꾼다.

17) 출력층에는 왜 활성화가 없을까

이번 목표는 숫자인 불량 값을 예측하는 회귀다.
은닉층에서 이미 비선형 변환을 했으므로 출력은 가중합만으로 만들 수 있다.
출력층 자체가 선형이어도 입력에서 출력까지의 전체 관계는 비선형일 수 있다.

은닉층의 a들이 0과 1 사이여도 가중치를 곱하고 더한 최종 값은 음수나 1보다 큰 수가 된다.
따라서 2.7703을 277%의 확률로 읽으면 안 된다.
실제 불량 수치가 음수가 되면 안 되는 문제에서는 모델 설계를 더 고려해야 한다.
이 파일은 우선 계산 흐름을 보여주는 예제다.

18) 활성화를 빼고 계산하면 어떻게 될까

def 순전파_활성화없음(x):
    z1 = W1 * x + b1
    z2 = W2 * x + b2
    return V1 * z1 + V2 * z2 + c

활성화 결과 a 대신 가중합 z를 바로 출력층에 전달한다.
현재 숫자를 넣어 괄호를 풀어보자.

y_hat = 4*(0.3*x - 6) - 3*(-0.2*x + 5) + 1
      = 1.2*x - 24 + 0.6*x - 15 + 1
      = 1.8*x - 38

계산 단계를 두 겹 거쳤지만 결국 직선 식 하나가 되었다.
'붕괴한다'는 말은 계산이 고장 났다는 뜻이 아니라 식을 하나로 줄일 수 있다는 뜻이다.
가중합만 여러 층 연결하면 계속 가중합 하나로 정리된다.

19) W_eff와 b_eff는 합쳐진 직선의 가중치와 절편이다

W_eff = V1*W1 + V2*W2
b_eff = V1*b1 + V2*b2 + c

eff는 여러 계산을 합친 효과를 나타내기 위한 이름이다.
새로 학습한 값이 아니라 현재 숫자들을 대수적으로 묶어 계산한 값이다.
현재는 W_eff=1.8, b_eff=-38이다.

abs(두층결과 - 직선결과) < 1e-9

abs는 차이의 부호를 뺀 크기를 구한다.
1e-9는 0.000000001이다.
컴퓨터의 소수 계산에는 아주 작은 오차가 있을 수 있어서 차이가 충분히 작은지 본다.
True이면 정한 허용 오차 안에서 두 계산이 일치한다는 뜻이다.

20) 이웃 차이를 보는 이유

온도는 10, 15, 20, 25, 30, 35, 40으로 똑같이 5씩 증가한다.
활성화가 없을 때 출력은 -20, -11, -2, 7, 16, 25, 34다.
옆 값과의 차이는 모두 9다. 온도 5 증가마다 1.8*5만큼 증가한다.

ys_lin[i + 1] - ys_lin[i]

i번 값에서 다음 값을 비교하는 계산이다.
range(len(온도)-1)은 0부터 5까지의 여섯 위치를 만든다.
점은 일곱 개지만 점 사이 간격은 여섯 개이기 때문이다.

같은 입력 간격에서 출력 차이가 다르면 그 점들이 직선 하나 위에 있지 않음을 알 수 있다.
반대로 몇 개 점의 차이가 같다는 관찰만으로 모든 중간 구간까지 직선임을 증명할 수는 없다.
이번에는 앞에서 식을 직접 1.8*x-38로 정리했기 때문에 전체가 직선임을 안다.

21) 시그모이드를 넣으면 달라지는 점

온도별 출력: 약 -1.67, -0.91, 0.81, 2.77, 4.00, 4.60, 4.85.
이웃 차이: 약 0.76, 1.72, 1.96, 1.23, 0.59, 0.25.

입력을 5씩 올려도 출력의 증가량은 일정하지 않다.
가파르게 변하는 부분과 완만하게 변하는 부분이 생긴 것이다.
이것이 비선형 활성화가 표현력을 넓히는 이유다.

다만 지금 나온 값은 계속 올라간다. 아직 U자 정답을 맞춘 것이 아니다.
현재 숫자는 계산 시연을 위해 임의로 정한 값이다.
비선형을 표현할 수 있는 구조와 실제로 원하는 모양을 배우는 일은 구별해야 한다.
활성화를 넣어도 가중치가 0이거나 효과가 상쇄되는 설정에서는 곡선이 드러나지 않을 수 있다.

22) 도함수는 입력 변화에 얼마나 민감한지 알려준다

활성화 입력 z를 아주 조금 올렸을 때 출력 a가 얼마나 바뀌는지 보는 값이 도함수다.
도함수가 크면 같은 작은 변화에도 a가 상대적으로 많이 변한다.
도함수가 0에 가까우면 z를 조금 바꿔도 a가 거의 변하지 않는다.

예: 도함수가 0.25인 곳에서 z를 아주 작게 0.001 올리면
a의 증가량은 대략 0.25*0.001 = 0.00025다.
이것은 작은 변화에 대한 근사이며 큰 변화까지 정확히 선형으로 예측한다는 뜻은 아니다.
09에서는 이런 변화의 관계를 거꾸로 이어서 가중치의 기울기를 계산한다.

23) 시그모이드 도함수는 a 곱하기 1 빼기 a

def sigmoid_도함수(z):
    a = sigmoid(z)
    return a * (1 - a)

z=0이면 a=0.5이므로 도함수는 0.5*0.5=0.25다.
z=2나 -2에서는 약 0.10499다.
z가 아주 크거나 아주 작으면 a가 1이나 0에 가까워져 도함수가 작아진다.
S자의 양 끝이 평평하기 때문이다.

작은 변화율을 여러 층에 걸쳐 곱하다 보면 앞쪽까지 전달되는 기울기가 작아질 수 있다.
이것이 기울기 소실을 이해하는 출발점이다.
실제 전체 기울기는 활성화 도함수뿐 아니라 연결 가중치 등에도 영향을 받는다.

24) ReLU 도함수는 구간에 따라 0 또는 1

def relu_도함수(z):
    return 1.0 if z > 0 else 0.0

한 줄 if는 조건이 참이면 앞 값을, 아니면 뒤 값을 고른다.
양수 구간에서는 z가 0.001 늘면 a도 0.001 늘므로 도함수 1이다.
음수 구간에서는 조금 바뀌어도 a가 계속 0이므로 도함수 0이다.

정확히 z=0에서는 꺾이므로 보통의 도함수가 존재하지 않는다.
이 코드는 학습 계산을 위한 약속으로 0을 선택한다.
ReLU의 양수 구간은 활성화 자체가 기울기를 줄이지 않는다.
하지만 음수 구간의 0은 기울기 전달을 막는다. 'ReLU는 항상 기울기가 줄지 않는다'는 뜻은 아니다.

25) 수치미분은 양옆을 살짝 움직여 비교하는 검사법이다

def 수치미분(f, z, h=1e-6):
    return (f(z + h) - f(z - h)) / (2 * h)

f에는 확인할 함수가 들어간다. h=1e-6은 기본 이동 거리 0.000001이다.
오른쪽 출력에서 왼쪽 출력을 빼고 두 입력 사이 거리 2h로 나눈다.
01~03에서 손잡이를 조금씩 움직여 본 것과 같은 중심차분 방법이다.

코드는 시그모이드 도함수의 공식값과 수치미분 결과 차이가 1e-6보다 작은지 확인한다.
선택한 점들에서 모두 True가 나왔다.
ReLU는 -2와 2에서 비교한다. 꺾이는 0은 이 검사에서 제외했다.
0에서 중심차분을 계산하면 0.5가 나오지만, 실제 도함수가 0.5라는 뜻은 아니다.
양쪽 기울기가 달라 도함수가 없는 점을 가로질러 평균 기울기를 계산했기 때문이다.

수치미분으로 학습할 수도 있지만 손잡이마다 여러 번 계산해야 해서 큰 모델에서는 비싸다.
역전파는 순전파에서 얻은 중간값을 활용해 기울기를 효율적으로 구한다.
역전파가 모델 크기와 상관없이 계산 한 번이면 끝나는 마법이라는 뜻은 아니다.

26) 활성화만 바꾸는 실습

for t in 온도:
    ys = 순전파(t, sigmoid)[0]
    yr = 순전파(t, relu)[0]

for는 각 온도를 t에 넣어 차례대로 반복한다.
같은 가중치와 같은 온도를 사용하고 활성화만 바꿔 비교한다.

온도 10 → sigmoid -1.668 / ReLU -8.000
온도 15 → sigmoid -0.913 / ReLU -5.000
온도 20 → sigmoid  0.807 / ReLU -2.000
온도 25 → sigmoid  2.770 / ReLU  7.000
온도 30 → sigmoid  4.003 / ReLU 13.000
온도 35 → sigmoid  4.598 / ReLU 19.000
온도 40 → sigmoid  4.848 / ReLU 25.000

숫자의 폭이 크다고 더 좋은 모델이라는 뜻은 아니다.
이 표는 활성화 선택이 계산 결과를 바꾼다는 것을 보여준다.
공정하게 어느 모델이 좋은지 비교하려면 각각 학습하고 별도 데이터로 평가해야 한다.

27) ReLU 그래프는 정확히 어디서 꺾일까

뉴런 1의 점수는 0.3*x-6이다. x=20에서 0이 된다.
뉴런 2의 점수는 -0.2*x+5다. x=25에서 0이 된다.
따라서 현재 ReLU 신경망의 꺾이는 지점은 20과 25다.

x가 20 이하: 첫 뉴런 결과는 0, 둘째 뉴런만 남아 y_hat=0.6*x-14.
x가 20부터 25: 두 점수가 모두 0 이상이므로 y_hat=1.8*x-38.
x가 25 이상: 둘째 뉴런 결과는 0, 첫째 뉴런만 남아 y_hat=1.2*x-23.

세 직선 조각이 이어진 모양이다. 경계점에서는 양쪽 식이 같은 값을 준다.
원본 설명의 '25부터 꺾인다'는 출력 목록을 쉽게 읽는 표현이고,
수식 기준으로는 첫 꺾임이 20, 두 번째 꺾임이 25라고 보는 것이 정확하다.
뉴런을 늘리면 더 많은 조각을 표현할 여지가 생기지만 자동으로 더 잘 맞거나 매끄러워지는 것은 아니다.

28) 순수 파이썬 계산을 NumPy로 묶기

W = np.array([W1, W2])
bh = np.array([b1, b2])
z = W * x + bh

np.array는 숫자 목록을 NumPy 배열로 만든다.
가중치 두 개에 같은 x를 곱하고 각자 편향을 더해 z1과 z2를 함께 구한다.
x=25라면 z 배열은 [1.5, 0.0]이다.

a = 1 / (1 + np.exp(-z))

math.exp는 여기서 숫자 하나씩 처리하지만 np.exp는 배열의 각 값에 계산을 적용한다.
a에는 약 [0.817574, 0.5]가 들어간다.

np.array([V1, V2]) @ a + c

여기서 @는 같은 자리끼리 곱해서 더하는 내적이다.
즉 V1*a1 + V2*a2 + c와 같은 계산이다.
float는 결과를 파이썬의 실수 하나로 바꾼다.
순수 파이썬과 NumPy 모두 약 2.7703이 나왔고 허용 오차 비교도 True였다.
표현 방식이 달라졌지만 모델이나 계산 원리가 달라진 것은 아니다.

29) 출력층 설정을 바꿨던 실험 다시 읽기

은닉층 W1, b1, W2, b2와 온도 25를 유지하면 a1과 a2는 변하지 않는다.
V1, V2, c를 바꾸면 같은 중간 재료를 섞는 비중이 달라진다.

(4, -3, 1)   → sigmoid 출력 약  2.7703 / 활성화 없으면 1.8*x-38
(10, -1, 5)  → sigmoid 출력 약 12.6757 / 활성화 없으면 3.2*x-60
(1, -5, -1)  → sigmoid 출력 약 -2.6824 / 활성화 없으면 1.3*x-32

어느 설정이든 활성화를 빼면 직선 하나로 정리된다.
이 설정들을 사람이 바꾸어 관찰하는 것은 실험이다.
정해진 학습 절차로 손실을 줄이도록 조절하는 것은 아직 하지 않았다.

30) 원본 주석에서 구별해서 읽을 부분

R²=0은 최저 점수가 아니다. 음수도 가능하며 이 예제에서는 평균 예측과 같다는 뜻이다.
02의 점수가 0.9를 넘었다는 주석은 현재 앞서 확인한 02 결과와 맞지 않는다.
현재 자료의 02 시험용 R²는 약 0.78이었으므로 예전 설명 수치를 그대로 외우지 말자.

입력 x=0과 활성화 입력 z=0은 다르다.
현재 x=0이면 z1=-6, z2=5이므로 a1과 a2가 모두 sigmoid(0)=0.5가 되지 않는다.
sigmoid(0)=0.5를 확인하려면 시그모이드 자체에 0을 넣어야 한다.

실수 계산은 실행 환경이나 출력 반올림에 따라 아주 작은 차이가 있을 수 있다.
표시 숫자가 다르면 먼저 실제 실행되는 가중치 설정과 주석 여부를 확인하자.
원본 코드 상단의 실행 예시 파일명도 실제 파일명과 다르므로 현재 파일명을 사용한다.

31) 작은 확인 실습

실습 A: 온도 25에서 ReLU를 직접 계산해보자.
힌트: z1=1.5, z2=0이다.
답: a1=1.5, a2=0이므로 y_hat=4*1.5-3*0+1=7이다.

실습 B: 활성화 없이 온도 30을 넣어보자.
답: 1.8*30-38=16이다. 두 층을 따로 계산해도 같은 값이 나온다.

실습 C: 시그모이드의 z=0에서 도함수를 구해보자.

실습 E: sigmoid를 넣었으니 현재 신경망이 U자를 맞혔을까?
답: 아니다. 비선형 계산은 가능해졌지만 정답을 맞추는 신경망 학습은 아직 하지 않았다.

32) 09로 넘어가기 전에 기억할 흐름

입력 x
→ 가중치와 편향으로 점수 z1, z2 계산
→ 활성화로 중간값 a1, a2 계산
→ 출력층에서 조합하여 예측 y_hat 계산.

이것이 순전파다.
다음에는 예측과 정답으로 손실을 계산하고,
각 손잡이가 손실에 미치는 변화를 역전파로 구한 뒤,
경사하강법으로 일곱 손잡이를 수정하는 과정이 연결된다.
순전파는 답 만들기, 역전파는 기울기 구하기, 업데이트는 손잡이 고치기로 구별하자.
